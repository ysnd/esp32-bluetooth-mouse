# ESP32 Bluetooth Mouse

DIY Bluetooth Mouse using ESP32 and MX8650 optical sensor and switches form salvage mouse.

## Features
- Left / Right click
- Middle click
- Thumb forward / back click
- Scroll wheel
- Horizontal scroll
- Bluetooth HID

## Hardware
- ESP32 DevKit V1
- Swithes
